# Nook & Form

A premium interior design studio platform built for showcasing interior projects, services, consultations, and design experiences.

## Overview

Nook & Form is a full-stack interior design platform with:

- Premium interior-design focused frontend
- Design portfolio and project showcases
- Service listings and service detail pages
- Consultation flow
- Admin dashboard
- Design, project, service, testimonial, and studio content management
- Cloudinary-based image management
- MongoDB database
- Clerk authentication
- Responsive UI for desktop and mobile

## Tech Stack

### Frontend

- Next.js
- React
- TypeScript
- Tailwind CSS
- Clerk
- Next.js App Router

### Backend

- Node.js
- Express
- TypeScript
- MongoDB
- Mongoose
- Cloudinary
- Clerk authentication
